## 📌 Ключевые проекты

### [TimeTracker (Таймтрекер)](https://github.com/PaulLeMot/Time-Tracker)
**СКУД-система для малого предприятия**
*Февраль 2026 – Июнь 2026*

- Разработал и внедрил систему учёта рабочего времени, которую ежедневно используют **30 сотрудников** предприятия уже более месяца.
- Провёл **ручное тестирование** всех сценариев: составил чек-листы, анализировал логи, исправлял баги, оптимизировал SQL-запросы.
- Стек: **FastAPI** (бэкенд), **PostgreSQL** (БД), HTML/CSS/JS (фронтенд), **Docker** (деплой).
- Интегрировал сканирование QR-кодов для отметки прихода/ухода.
- Внедрил **SSE** (Server-Sent Events) для обновлений в реальном времени.
- Автоматизировал запуск и проброс портов через **bash-скрипты** внутри WSL.
