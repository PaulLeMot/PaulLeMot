## 📌 Ключевые проекты

### ⏱️ [TimeTracker — система учёта рабочего времени](https://github.com/PaulLeMot/Time-Tracker)

**Реальное внедрение · 2026 · ~30 пользователей ежедневно**

**Стек:** `Python` · `FastAPI` · `SQLAlchemy` · `PostgreSQL` · `Alembic` · `Docker` · `HTML/CSS/JS`

Разработал приложение для учёта рабочего времени на предприятии — от бизнес-логики и базы данных до интерфейса, развёртывания и поддержки.

- Реализовал **REST API** для управления сотрудниками, регистрации событий и построения отчётов.
- Настроил учёт **прихода, ухода и перерывов по QR-кодам**, включая проверку допустимых последовательностей действий.
- Разработал административные функции, отчётность и обновление данных в реальном времени через **SSE (Server-Sent Events)**.
- Использовал **PostgreSQL**, асинхронный **SQLAlchemy** и **Alembic** для миграций схемы БД.
- Настроил запуск приложения через **Docker Compose**, занимался диагностикой и поддержкой серверного окружения.
- Проверял пользовательские сценарии, анализировал логи, находил и исправлял ошибки.

🔗 **[Исходный код TimeTracker](https://github.com/PaulLeMot/Time-Tracker)**

### 🛒 AST — интернет-магазин автозапчастей

**В разработке · 2026**

**Стек:** `Next.js` · `React` · `TypeScript` · `Tailwind CSS` · `Medusa.js`

Разрабатываю веб-приложение для магазина автозапчастей с каталогом товаров, поиском и подбором по автомобилю.

- Создал **адаптивные страницы** и переиспользуемые React-компоненты.
- Реализовал **каталог товаров** с поиском, категориями и фильтрами в URL.
- Разработал **многоступенчатый подбор автомобиля**: марка → модель → поколение → двигатель.
- Организовал слой взаимодействия с каталогом автомобилей через **API и абстракцию провайдера данных**.
- Работаю над интеграцией каталога и товарных страниц с **Medusa.js**.
